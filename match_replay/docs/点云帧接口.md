# 点云帧接口（v1）

2026-10-15。提供 Unity 进程内扩展接口，录制、导出、Python/ROS 传输与算法实现仍未接入。

在 Unity 主线程获取 `ReplayViewer.LidarFrames`，返回 `ILidarFrameSource`。订阅不自动启用扫描；仍由原点云开关控制。没有帧订阅且 `RetainLatestFrame=false` 时，不分配点云快照。仅订阅重置通知也不产生快照。

## 订阅与取帧

```csharp
ILidarFrameSource source = viewer.LidarFrames;
IDisposable subscription = source.Subscribe(
    frame => {
        // 快照可直接交给有界队列/最新帧邮箱，回调本身不要跑重算法。
        // frame.Points 是本次扫描，不含显示累积；保留后不会被下一帧覆盖。
    },
    change => {
        // 清空算法的旧帧邮箱、跟踪状态；记录 change.Epoch。
    });

// 可选：需要主动拉取时保留至多一份最新快照。
source.RetainLatestFrame = true;
if (source.TryGetLatestFrame(out LidarScanFrame frame)) {
    // 可在工作线程读取不可变帧；使用前核对 frame.Epoch == source.Epoch。
}

// Unity 主线程清理；可重复 Dispose。
subscription.Dispose();
source.RetainLatestFrame = false;
```

订阅、解除订阅和配置在主线程执行；回调也在主线程，不调用外部算法阻塞渲染。`TryGetLatestFrame` 和已获取的不可变帧可以在工作线程读取。调用者自己保留的历史快照不会因清理失效，但其代次可能过期；跨时间跳转时必须检查 `Epoch`。

快照拥有独立数据，内部数组不暴露、没有显式释放期限。消费者不得无限保存快照或排入无界队列；建议仅保存最新一帧。接口自身只保留一个最新帧，且只在 `RetainLatestFrame=true` 时保留。订阅者异常会被隔离，不中断扫描或其他消费者。

## 数据约定

| 字段 | 含义 |
|---|---|
| SchemaVersion | 接口格式版本 1 |
| Sequence / Epoch | 扫描序号 / 生命周期代次；代次改变后旧帧不能作为当前输入 |
| Mode / GameId / FieldId | 回放或开发者模式、比赛身份、实际展示场地身份；开发者 GameId 为空 |
| SimulationTimeSeconds | 扫描开始的仿真时间，来自回放时间轴或开发者时钟，不是 UTC 或实车时间 |
| DurationSeconds | 配置扫描帧周期 1/Hz；不是物理求交的墙钟耗时 |
| RequestedHz / QualityPercent / AttemptedRays | 扫描配置和本帧发出的射线数量 |
| Points | 原始单帧第一回波；零命中仍是一份有效空帧 |
| WorldPosition / RangeMetres | Unity 世界米制 XYZ / 从对应机位到命中的距离 |
| SensorId | 0 红、1 蓝；双机位帧包含两方数据，不能用列表下标推定单机位身份 |
| TimeOffsetSeconds | 相对帧开始的模拟扫描顺序时间，不是实测逐点时间 |
| Sensors | 本次查询开始时冻结的各机位位置与旋转；提供 WorldToSensor / SensorToWorld |

统一坐标为 Unity 左手坐标：X 向右、Y 向上、Z 向前；机位局部坐标同样右/上/前。转成 ROS 等坐标需要单独处理轴顺序及左右手性，不能直接复制 XYZ。外参记录于扫描启动时，UI 后续调整不修改已发布快照。

`HasReflectivity=false`、`HasLineNumber=false`。当前没有可信反射率、line、IMU、多回波或逐点动态畸变，不能伪造为 Livox 原生数据；几何在整帧求交期间冻结，`GeometryFrozenForFrame=true`、`IsApproximateScan=true`。显示累积不改变 API 的单帧含义。

## 生命周期

启用、关闭、回放跳转、换局、换场地、场景几何/设置修改及清空时，最新帧被撤掉并发出 `StreamReset`，代次单调递增。销毁 Viewer 时通知 `Disposed` 并解除所有订阅。通用场景重建使用 `SceneChanged`；特定入口提供 `TimelineJump`、`MatchChanged`、`FieldChanged`、`SettingsChanged` 等原因。

关闭扫描或返回菜单后不继续生产帧。暂停且几何未改变时不重复生产相同扫描。接口完全独立于显示积累、GPU 缓冲区和扫描内部可复用数组。

## 验收入口

`ReplayBuild.Verify` 运行纯契约检查；原生程序 `--lidar-api-smoke OUTPUT` 检查真实双机位帧、外参/时间、保存快照、显示累积分离、跳转与换局/场地、关闭及解除订阅。`--replay-lidar-smoke OUTPUT` 继续覆盖持续运行与闪退回归，`--lidar-smoke OUTPUT` 覆盖开发者生命周期。
