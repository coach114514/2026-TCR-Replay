实际点云测试在 Linux X11/Xwayland、RTX 5060 Laptop GPU、1600×900 下执行。未提供跨硬件 FPS 保证；有订阅时会分配独立快照，算法应使用有界最新帧邮箱，不能阻塞 Unity 回调。

修复 Linux System.Math.Cos → AviaDirection 的原生 SIGFPE：相位计算改为纯托管周期归约与多项式，方向回归覆盖原公式参考值。没有据此宣称已定位所有 CPU/驱动/运行库底层缺陷。

持续点云验收核对最新原始扫描与同一冻结求交场景；历史显示累积包含旧姿态，不能用当前车辆几何判为“穿透”。

原生程序入口：

```bash
./TCRReplay.x86_64 --lidar-api-smoke /tmp/tcr-lidar-api
./TCRReplay.x86_64 --replay-lidar-smoke /tmp/tcr-lidar-replay
./TCRReplay.x86_64 --replay-smoke
```

开发者物理、牵引、机关与车辆专项需要完整本地资源；公开示例入口关闭时不应运行这些专项。历史堡垒测试的 512 用例受助跑、辅助开启及满电等条件约束，不能用作真实机械通行证明。导航仍有未完成项，见 KNOWN_ISSUES。
